What are arrays ? Its a variable that can store multiple values with a fixed size and can be manipulated by repeating structures, conditions, switches and many others.

EX: String[] name = {"value",anothervalue};

Its possible to place a fixed size applyng a previous array, like:
String[] name = new string[size];

And to place another value we usually apply the array itself and the spot.
EX: name[spot] = value;
